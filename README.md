# 🎓 Student Grading System

A beginner-friendly Java application that calculates student totals, averages, grades, and academic status.

## 📌 About the Project

This project is part of my journey toward becoming a software developer and AI engineer. I'm building practical projects while strengthening my Java programming and object-oriented programming fundamentals.

## ✨ Features

- 📝 Stores student names and marks.
- ➕ Calculates total marks across three subjects.
- 📊 Calculates the student's average.
- 🏆 Assigns a grade based on the average.
- ✅ Determines the student's academic status.

## 🛠️ Technologies Used

- **Language:** Java
- **IDE:** Eclipse
- **Concepts:** Classes, objects, methods, arrays, loops, conditionals, and user input.

## ▶️ How to Run

1. Install a Java Development Kit (JDK).
2. Open Eclipse.
3. Import or create a Java project.
4. Place `Main.java` and `student.java` in the `inPractice` package.
5. Run `Main.java` as a Java application.
